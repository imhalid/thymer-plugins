# Cursor FX textures

Both are CC0 (public domain); credit is not required but given here.

- `atlas.png` - 18 sprites from **Particle Pack** by Kenney (kenney.nl), CC0
  (https://opengameart.org/content/particle-pack-80-sprites), turned grayscale and scaled to 128x128 cells, in this order
  (6 per row): circle_02, circle_04, star_06, star_09, star_08, circle_05 / magic_01, magic_02, magic_03, magic_04,
  magic_05, twirl_01 / twirl_02, twirl_03, symbol_01, symbol_02, scorch_02, trace_02.
- `noise.png` - "Perlin 1" from **700+ Noise Textures** by Screaming Brain Studios, CC0
  (https://opengameart.org/content/noise-texture-pack), 128x128, contrast stretched. It tiles on both axes.
